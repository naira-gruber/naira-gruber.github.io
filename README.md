Para publicar el blog, asumiendo que Hexo está instalado en el sistema:

1. Realizar cambios
2. Con los comandos `hexo clean && hexo generate` se genera una nueva versión
3. Con `hexo server` servimos localmente el blog y comprobamos los cambios antes de subirlos a la versión pública
4. Finalmente `hexo deploy` sube los cambios a este repositorio y lanza el flujo de publicación
